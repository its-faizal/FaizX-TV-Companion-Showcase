# Reporting a security issue

Please use [GitHub private vulnerability reporting](https://github.com/its-faizal/FaizX-TV-Companion-Showcase/security/advisories/new) for suspected security vulnerabilities. Do not disclose the issue or sensitive data in a public issue first.

Include the app version, affected feature, prerequisites and a redacted reproduction. Describe the expected and observed behaviour. Never send private keys, passwords, active pairing tokens or personal media.

General connection and compatibility problems belong in the [connection guide](docs/connecting.md) or a redacted support issue. Please distinguish an app defect from a TV firmware restriction.

Reports are reviewed before a fix or security claim is published. No response-time or vulnerability-free guarantee is made.
