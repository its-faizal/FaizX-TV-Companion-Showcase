# Changelog

## 1.0.1 — 23 November 2026

- Bound APK imports and bundle extraction by actual bytes, file count and available cache space.
- Reject unsafe and conflicting APK archive names; clean partial files after failed or cancelled imports.
- Reduce decode-memory pressure for unusually wide or tall wallpaper images while preserving normal 4K input.
- Share diagnostics through a user-selected destination without a fixed recipient or premature attachment grants.
- Update product sharing and release links to the current FaizX repository.
- Preserve the established remote interface, gestures and device-management screens.

The [production-signed release](https://github.com/its-faizal/FaizX-TV-Companion-Showcase/releases/tag/v1.0.1) includes the Android APK, matching application source, SHA-256 checksums and packaging-verification metadata. The package is `tv.faizx.companion`, version code 39. Interface previews are separate from release artifacts.
